# CSSCI财经管理论文深度润色系统

将中文财经管理类论文改写为符合高水平CSSCI期刊表达规范的学术论文。

## 特点

- **完全离线运行**，无需API Key，不依赖任何外部服务
- **规则驱动改写**：基于CSSCI期刊表达规范，逐句分析并改写
- **6阶段改写流水线**：段落分类 → 口号化替换 → AI痕迹清除 → 开头改写 → 过渡语补充 → 贡献结论重构
- **12维度诊断**：制度背景切入、理论张力构建、研究问题聚焦等
- **逐句修改详情**：每处修改均展示 原文 → 改写 → 原因

## 安装与运行

```bash
npm install
npm run dev
```

运行后访问 http://localhost:3005

## 使用方式

1. 上传论文文件（.txt / .md / .docx）或粘贴论文全文
2. 选择改写范围（整篇论文 / 特定部分）
3. 点击「开始改写」
4. 查看改写版论文、修改详情、诊断报告和原文对照

## 系统功能

- **改写版**：按照CSSCI期刊规范生成的完整改写版论文
- **修改详情**：逐句展示每一处修改的原文、改写和原因
- **12维度诊断**：制度背景切入、理论张力构建、研究问题聚焦、文献批判对话、假设推导严密性、变量测度有据、机制分析深度、贡献表达具体化、语言克制精确、结论回扣问题、结构完整性、实证设计匹配度
- **导出功能**：Markdown / Word / 复制到剪贴板
- **原文对照**：左右分栏对比原文和改写版

## 改写原则

- 制度背景切入 → 从中国情境提出研究问题
- 口号化替换 → "赋能""驱动""显著提升"等替换为精确学术表达
- AI痕迹清除 → 删除"值得注意的是""需要指出的是"等AI高频用语
- 过渡语补充 → 插入"基于此""进一步看""由此可见"等学术连接语
- 贡献对比 → "已有研究…→本文…"结构
- 结论回扣 → 从实证发现中自然推出启示

## 注意事项

- 系统不改变作者原始研究结论
- 不编造文献、数据和实证结果
- 改写基于规则匹配，用户需自行核验修改是否恰当
- 不承诺论文一定发表
